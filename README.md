# NANA OPTOM — Assignment 3

## Project Description
NANA OPTOM is a responsive cosmetics website developed for the Introduction to Web Technologies course.

In Assignment 3, the existing HTML and CSS website was updated using Bootstrap 5.3.3 to improve its layout, navigation, forms, and responsiveness.

## Website Pages
- `index.html` — Home
- `products.html` — Products
- `order.html` — Order
- `about.html` — About
- `feedback.html` — Feedback
- `login.html` — Login

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5.3.3
- Visual Studio Code
- GitHub

## Project Structure
- `css/base.css` — shared website styles
- `css/aida.css` — Products and Order styles
- `css/assiya.css` — About and Feedback styles
- `css/login.css` — Login page styles
- `images/` — website images

## Bootstrap Features
- Responsive grid system
- Containers, rows, and columns
- Responsive navigation bar
- Bootstrap forms and buttons
- Spacing and alignment utilities

## Authors
Aida Khalila and Assiya Yesmagambet

## How to Run
Download or clone the repository and open `index.html` in a web browser.

The website is a front-end educational project. Forms and login are for demonstration purposes.
